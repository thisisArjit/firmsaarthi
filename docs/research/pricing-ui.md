# Pricing interface patterns — 26 October 2026

Official references reviewed:

- https://slack.com/pricing — named plan comparison, clear billing basis, plan-specific action and feature inclusion.
- https://www.notion.com/pricing — side-by-side plan comparison and clear audience/seat distinctions.

Logistrace adaptation: four explicit cards (the user requested all four choices together), real annual totals rather than monthly-equivalent headline prices, calculated annual savings only when positive, consistent unlimited-usage wording, one-login versus shared-team distinction and a separate activation confirmation section. No invented popularity badge, automatic payment, checkout or unsupported features.

Sign-in stays task-focused. Authenticated billing state determines the trial/expiry upgrade prompt. Paid, exempt and platform administrator access must not be treated as trial or sold a plan unnecessarily. Existing manual payment, tenant isolation and authorization are unchanged.
