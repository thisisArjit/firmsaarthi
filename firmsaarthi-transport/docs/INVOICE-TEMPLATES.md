# Invoice layouts

27 October correction: the previous default was a simplified PDF and did not reproduce the original HTML/CSS. New default snapshots and explicit reissues now carry defaultLayout=stta-html-v1 and use lib/original-invoice-pdf.ts, transcribed from the original TMS/InvoiceTemplate.html. It matches the asymmetric A4 margins, typography/proportions, six-column table, charges table, references/summary, conditional advance/GST, amount in Indian words, bank/QR and electronic-signature footer. Dates use dd-MMM-yyyy and rupee glyphs are drawn without introducing a licensed font dependency. Custom layouts still take precedence. Snapshots without the version marker retain the prior renderer; archived PDF download handling is unchanged. No original Apps Script file was edited and no issued snapshot was migrated.

Validation uses identical synthetic fixtures against the original GAS HTML template and the PDF: browser-measured reference geometry, rendered PNG inspection, text/item/total checks and long-invoice pagination. The PDF renderer is an A4 vector transcription rather than server-side HTML/browser execution. Source-owned templates are never accepted as executable uploads. scripts/preview-original-invoice.mjs generates local synthetic comparisons; it does not issue records. Production STTA has no saved invoice-template override, so the corrected default needs no customer settings mutation.

Owners: Settings → Invoice template (a separate tab since release 29). The original Shri Tiwari layout remains active until an owner saves a custom layout. Restore current default returns future invoices to that renderer. Existing invoice snapshots and archived original PDFs remain unchanged. Explicit authorized reissues snapshot the current template; downloads never adopt later settings.

Editor: title, orientation, readable accent, column labels/visibility, section order, notes, signatory and saved logo/QR visibility. Required totals/sections remain; consignment number and freight cannot be removed. Standard PDF fonts support Latin text; unsupported characters are omitted. Preview uses a synthetic invoice without issuing records.

Versioned Logistrace JSON import/export is bounded to 16 KB. Download exports the editable structured layout, not a pixel-exact conversion of the original default. Arbitrary PDF/Word/HTML, scripts and external image URLs are unsupported. Import loads a draft; Save applies it. Edits clear stale previews. Refresh retains drafts; stale saves require reload.

Owner-only, cookie-authenticated, same-origin, subscription-gated `/api/invoice-template` handles state/preview/save/reset. Settings use a separate organization-scoped, audited, versioned table included in owner backup. Profile saves cannot overwrite it. Migration 0022 only adds this table and optional prospect contact fields; no financial records are migrated.

Verification: service isolation, versions, immutable snapshots/P&L, reset/default; HTTP auth/CSRF/size/format/preview and role checks; browser import/save/preview/default and contextual invoice review. Synthetic 35-consignment default/portrait/landscape PDFs were checked for every item and total and visually inspected for pagination.
